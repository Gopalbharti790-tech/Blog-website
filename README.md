# Blog Website

A modern blog website built using Python, Django, HTML, and CSS.

This project allows users to read blog posts, explore articles, and navigate through a clean and responsive interface.

---

# Features

- Home Page
- All Blog Posts Page
- About Us Page
- Contact Page
- Responsive Navigation Bar
- Beautiful Blog Post Cards
- Static Image Support
- Django Template System
- Admin Panel
- Dynamic Post Rendering

---

# Technologies Used

- Python
- Django
- HTML5
- CSS3
- SQLite
- Bootstrap (Optional)

# Installation

## Clone Repository

```bash
git clone https://github.com/your-username/blog-website.git
```

## Move Into Project Folder

```bash
cd blog-website
```

## Run Server

```bash
python manage.py runserver
```

# Open Website

```bash
http://127.0.0.1:8000/
```
